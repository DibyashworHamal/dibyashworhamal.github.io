## 🏗️ Cloud-Native Deployment Architecture ($0 Cost Setup)
As a DevOps professional, I believe in infrastructure efficiency and Cloud Cost Optimization (FinOps). I architected this portfolio to be highly available, secure, and fast at **zero recurring cost** using the following stack:

* **Hosting & CI/CD:** [GitHub Pages](https://pages.github.com/) (Automated static site deployment directly from the `main` branch).
* **Domain Registry:** Mercantile Communications (Official `.com.np` domain for Nepalese citizens).
* **DNS, CDN & Security:** [Cloudflare](https://www.cloudflare.com/) (Acting as a reverse proxy to provide Edge Caching, DDoS protection, and strict SSL/TLS HTTPS encryption).
* **Backend Routing:** [Web3Forms API](https://web3forms.com/) (Serverless backend for secure contact form submissions).

## 💻 Running the Project Locally
To view or test the source code on your local machine:

1. Clone this repository:
   ```bash
   git clone https://github.com/DibyashworHamal/dibyashworhamal.github.io.git
   ```

2. Navigate into the directory:
   ```bash
   cd dibyashworhamal.github.io
   ```

3. Open the `index.html` file in any modern web browser, or use the "Live Server" extension in VS Code for hot-reloading.
